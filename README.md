# إلى مي... | إنتِ عمري 🤎

موقع وتجربة بصرية وشعورية تفاعلية مستوحاة من أغنية كوكب الشرق أم كلثوم "إنتِ عمري"، مُهداة إلى **مي**.

## ✨ المميزات والتصميم الديناميكي

- **تصميم متجاوب بالكامل (Mobile & Desktop Fluid Experience):**
  - يدعم جميع أجهزة الهواتف الذكية بدقة شاشات Retina / HiDPI ووحدات القياس الحديثة `100dvh`.
  - معالجة كاملة لاتجاه القراءة من اليمين لليسار (RTL) في خط الزمن الزجاجي (Timeline) مع نبضات ذهبية متوهجة.
  - الحفاظ على ميلان الورقة القديمة الطبيعي (-0.4°) والظلال الغنية على الهاتف كما على سطح المكتب.
- **تأثيرات لمس وتفاعل ديناميكية (Dynamic Touch Sparkles):**
  - تناثر غبار النجوم الذهبي عند اللمس أو التمرير على شاشة الهاتف بدقة 60 إطار بالثانية.
  - دعم إلغاء قفل الصوت التلقائي لمتصفحات الهواتف (iOS Safari & Android Chrome).
- **أقسام التجربة:**
  1. **شاشة البداية (Start Overlay):** لمسة أولى لبدء الموسيقى والتأثيرات.
  2. **الإهداء (Intro):** ظهور سينمائي لاسم "إلى مي...".
  3. **الظرف والختم الشمعي (Wax Seal & Envelope):** فتح ثلاثي الأبعاد بتأثير شمعي حقيقي مع حرف M.
  4. **رسالة القلب (The Romantic Letter):** ورقة كلاسيكية بخط الرقعة والأميري مع اقتباس أم كلثوم.
  5. **محطات الذكريات (Milestone Timeline):** بطاقات زجاجية فاخرة (Glassmorphism) تتنقل بسلاسة عبر التمرير.
  6. **مشهد القمر وسماء النجوم (The Moon & Celestial Stars):** قمر مضيء بتأثير بارالاكس عميق.
  7. **الخاتمة ورمز اللانهاية (Infinity & Forever):** إهداء نهائي لـ "مي" مع نبض شعاعي مضيء ورمز ∞.

## 🛠 التقنيات المستخدمة

- HTML5 Semantic Structure
- Pure Modern CSS (Glassmorphism, CSS Custom Properties, Viewport Safe Areas, Clamp Fluid Typography)
- Vanilla JavaScript & Web Audio API (Ambient Piano Synthesizer)
- GreenSock Animation Platform (GSAP 3 & ScrollTrigger)
- HTML5 Canvas 2D Particle & Star Engine (Retina DPI Scaled)
